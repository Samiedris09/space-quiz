# Cosmic Quest

Cosmic Quest is a dependency-free space exploration quiz built as a single static web page. It includes 10 questions, score and progress tracking, accessible answer feedback, light and dark themes, and a celebratory results screen for high scores.

## Run locally

No installation, build step, or local server is required.

1. Clone or download this repository.
2. Open `index.html` in a modern web browser.

The site can also be served by any static file server if preferred.

## Accessibility

- Native keyboard-accessible controls
- Visible focus states and logical focus order
- Correct and incorrect states communicated with text and color
- Light and dark themes using `prefers-color-scheme`
- Reduced animation using `prefers-reduced-motion`
